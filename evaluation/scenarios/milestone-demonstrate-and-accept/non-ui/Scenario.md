# Non-UI Demonstrate and Accept Scenario

## Purpose

Evaluate whether Loopy chooses an understandable outcome-focused Demo for an exact non-visual result instead of forcing a browser-shaped walkthrough or presenting raw technical output as human judgment.

## Controlled start

In a fresh disposable Human workspace, prepare one exact independently passing Milestone Build Candidate whose committed observable surface is an API, CLI, library, data workflow, or another non-UI form. Choose a held-out domain and acceptance boundary for each independent run rather than encoding a production answer here. Keep Definition, Plan, Proof, candidate, environment, and evidence anchors current.

## Independent run

Ask in ordinary language to demonstrate the outcome. Loopy should derive a method from the actual surface and available tools—for example a request/response, terminal interaction, executable use example, or controlled input/output—while keeping exact commands and logs linked below the digestible summary. Exercise an unavailable or unsafe action, partial or unproven observation, or changed authority so the run tests truthful stopping rather than only a happy path.

First verify the operated process, endpoint, library build, or data target against the exact candidate and expected environment. Evidence must remain independently resolvable from `Demo.md`; session-only output is marked inaccessible unless preserved durably. Then provide a clear human acceptance, correction, or deferral in ordinary language. A simulated participant response or proxy AI assessment may be supplied as context but must remain advisory and never be recorded as personal human review or decision.

## Evaluation boundary

Preserve the complete multi-turn transcript, exact candidate and workspace, grants, actions, outputs, `Demo.md`, `LOOPY.md`, `Roadmap.md`, limitations, and evaluator judgment. Builder coaching or inherited implementation context invalidates the behavioral claim. Report whether another human can explain what was demonstrated, what remains unproven, who judged it and from what perspective, and why the result is Complete-but-unreleased or routed back.
