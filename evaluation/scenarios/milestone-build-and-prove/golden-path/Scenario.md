# Milestone Build and Prove Golden Path

## Purpose

Carry the existing controlled Harbor Product → Engineering → Roadmap → Definition → Plan fixture through bounded Build and independent Proof mechanics without executing real product or external-system mutations.

## Setup

Use the committed customer-recovery Definition and ready two-Work-Unit Plan created by the existing versioned fixtures. Record inert SHA-256 source/workspace fingerprints. The Plan contains either no focused checkpoint for its low-risk path or one justified focused checkpoint plus exactly one mandatory final integrated independent boundary.

## Expected path

1. A Work Unit-scoped grant names responsibility, workspace, tools, local source-control scope, external systems, model/cost choices, and the activated evaluation budget.
2. A builder task records the actual available host/model/settings/qualification. Required-before work runs first; parallel work is allowed only in the explicit safe fixture.
3. Ordinary work persists canonical state without noisy `Proof.md` republication. Pause, failure, status, explicit request, and final readiness publish synchronized views.
4. A focused failed candidate remains immutable. A corrected candidate names its parent and consumes one cycle. Zero-limit exhaustion pauses; an increase requires explicit human judgment.
5. The final evaluator is distinct from every builder, receives an exact neutral-unproven charter, and judges one frozen integrated candidate.
6. Final PASS becomes ready for Demonstration only when every committed acceptance criterion and planned check has supported declared coverage linked to inspectable evidence.

## Required assertions

Rejected authority, stale source/workspace, dependency, parallel, charter, coverage, and budget operations leave state, history, `LOOPY.md`, `Roadmap.md`, and `Proof.md` byte-identical. Human views contain readable Work Unit names and evidence/provenance, not internal identities. No Demo, Acceptance, completion, Release, push, merge, deployment, publication, or real external mutation occurs.
