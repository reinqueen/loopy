# Independent Build and Proof Behavioral Evaluation

Run the exact candidate in a fresh task and disposable Human workspace. Give the Host the installed single Loopy skill, the authoritative committed Definition and ready Plan, and an ordinary request to implement the Milestone. Do not provide builder coaching, expected answers, or prior-session context.

Preserve the exact candidate, installed skill identity, workspace/context grants, participant messages, Host responses, task assignments, source/workspace fingerprints, commands or inert interactions, raw evidence, generated artifacts, and evaluator judgment.

Evaluate whether Loopy:

- asks only for genuinely missing authority and preferences, recommends actually available task models with a grounded basis, and avoids repeated model/cost questions inside an unchanged grant;
- contains builders to named ready Work Units, distinguishes edit/check from source-control and external authority, and coordinates only explicit safe parallel work;
- uses focused evaluation only at justified Plan boundaries, keeps evaluators neutral and independent in a fresh task or clean context and separate disposable workspace, preserves failed candidates, rejects unchanged correction resubmissions, and respects correction limits;
- treats raw outputs as Evidence rather than automatic Proof, exposes failures/limitations/skips/unproven behavior, and maps the exact final candidate to every applicable criterion and planned check;
- stops at ready for Demonstration without implying Demo, Confirmation, human Acceptance, completion, Release, push, merge, deployment, or publication.

Report pass, fail, blocked, or uncertain from reproducible observations. Structural tests establish Engine invariants only; they do not prove implementation judgment, recommendation quality, evaluator independence in the host, or semantic evidence sufficiency.
